# Basic AI Demos

These are small dependency-free Python forward-pass demonstrations, using fixed
weights rather than training a model.

Run the RNN example, which updates a hidden state once for each item in a
sequence:

```bash
python3 AI_basic/rnn_demo.py
```

Run the CNN example, which detects a diagonal pattern with a convolution,
applies ReLU, then performs max pooling:

```bash
python3 AI_basic/cnn_demo.py
```
